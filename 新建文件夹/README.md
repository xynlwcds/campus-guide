# 🎓 校园生活指南网站

一个现代化、响应式的校园生活指南网站，为学生提供全面的校园信息和服务。

## ✨ 主要功能

### 📱 页面模块

1. **首页横幅**
   - 欢迎信息展示
   - 智能导航引导

2. **快速导航**
   - 校园地图入口
   - 教室分布入口
   - 快递站点入口
   - 重要地标入口

3. **校园地图**
   - 校园平面图展示
   - 教学区位置
   - 宿舍区分布
   - 图书馆位置
   - 餐饮区分布
   - 运动场馆
   - 行政办公区

4. **教室分布**
   - A栋教学楼（主楼）- 4层，120间教室
   - B栋教学楼（实验楼）- 4层，专业实验室
   - C栋教学楼（艺术楼）- 4层，艺术类教室
   - D栋教学楼（工科楼）- 4层，实训工场
   - 每栋楼详细楼层分布
   - 教室设施说明

5. **快递站分布**
   - 东区快递站（最热门）
   - 西区快递站（便利）
   - 南区快递站（新建）
   - 北区快递站（全天候）
   - 支持快递品牌
   - 营业时间和联系方式
   - 取件须知和温馨提示

## 🎨 特色亮点

- ✅ **响应式设计** - 完美适配手机、平板、电脑
- ✅ **平滑滚动** - 流畅的页面导航体验
- ✅ **动画效果** - 滚动动画、悬浮效果
- ✅ **现代UI** - 渐变色、阴影、圆角设计
- ✅ **交互增强** - 导航栏高亮、移动端菜单
- ✅ **表单验证** - 意见反馈表单功能

## 🚀 如何使用

### 方法一：直接打开
1. 在文件管理器中找到 `index.html`
2. 双击文件，使用浏览器打开

### 方法二：使用本地服务器（推荐）
如果你安装了 Python：

```bash
# Python 3
python -m http.server 8000
```

然后在浏览器访问：`http://localhost:8000`

## 🔧 自定义修改

### 修改颜色主题
在 `styles.css` 中修改 CSS 变量：

```css
:root {
    --primary-color: #4A90E2;     /* 主色调 */
    --secondary-color: #50C878;   /* 辅助色 */
    --accent-color: #FF6B6B;      /* 强调色 */
}
```

### 修改内容
直接编辑 `index.html` 中的文本内容即可。

### 添加新功能
在 `script.js` 中添加新的交互逻辑。
